# ComfyUI 全能插件 — 使用教程

AstrBot 插件，连接本地/云端 ComfyUI，实现**文生图、图生图、图生视频、图片编辑**。自带 WebUI 可视化面板（赛博魔法主题）、魔导书提示词库。

**🎉 v4.2.0 更新（Anima 词库升级 + 全量汉化）：**
- 🌐 **数据源迁移到 animadex API** — 源站已从静态 JS 改为 API 架构（旧 `data.js`/`character_data.js` 在远端已下线）。画师/角色改从 `/api/artists/search`、`/api/characters/search` 拉取
  - **画师**：标签自动规范为 `@名字`（原名形如 `hammer \(sunset beach\)`，带括号会与权重语法 `(...)` 冲突）；只收有图的
  - **角色**：含规范触发词（`hatsune miku, vocaloid`）、**外观标签数组**（`["1girl","aqua eyes",...]`）、配套 Lora 推荐
- 🖼️ **修复图片全部空白** — 旧图片域名 `anima.mooshieblob.com` 已失效（返回 `text/html` 而非图片）；改用 `blobs.animadex.net`，角色图片 URL 需把原名里的冒号转下划线（实测 100% 命中）
- ⚡ **并发分页拉取** — 源 API 每页固定 36 条（`limit` 参数无效），全量需 1000+ 页；改为 8 线程分批拉取，**画师 9072 条 + 角色 35372 条约 10 分钟**（串行需 40+ 分钟）
- 💾 **三级容错** — 读本地缓存 → 拉 API → 回退 JS；缓存位于 `data/user/`，首次拉取后永久可用
- 🇨🇳 **全量汉化** — 角色名与 IP/系列名 **100% 中文**（35372 + 3651 条）
  - 新增 `name_cn` / `category_cn` 字段，前端**优先显示中文**，**支持中文搜索**（搜"初音"能出 55 条）
  - 示例：`Hatsune Miku → 初音未来`、`Frieren → 芙莉莲`、`Rem (Re:zero) → 雷姆`、`Genshin Impact → 原神`
  - 画师人名保留原文（译名无意义）
- 📚 **词库扩充 + 官方规范**
  - 新增「官方规范」38 条：品质（masterpiece/best quality…）、评分（score_9~5）、年代（year 2025/newest…）、Meta（absurdres/anime screenshot）、安全（safe/sensitive/nsfw/explicit）、主体数（1girl/solo/2girls/no humans）
  - 扩充 7 个薄弱分类：肤质 3→25、年龄段 6→15、内衣泳装 5→30、连衣裙 7→28、金属 5→16、皮革 6→16、画风技法 6→25
  - **词库总量 780 → 935 条**
- 🎯 **Anima 随机规范增强**（WebUI 开关，默认开）
  - 固定开头：`masterpiece, best quality, score_7, safe`（去重后前置）
  - 自动补主体数：池子里没抽到 `1girl/solo` 等时自动补
  - **末尾追加 2 句自然语言**（符合官方"tag + 自然语言混合写"要求）
  - ⚠️ `score_7` 适用于 Base 版模型，**Aesthetic 版请关闭本项**
- ⚙️ **新增配置**：`anima_artist_limit` / `anima_character_limit`（默认 `0` = 全量）、`anima_spec_enhance`（默认开）

**🎉 v4.1.0 更新（飞书适配）：**

  - `comfyui_get_current_workflow` 也带分类与用途
  - `comfyui_draw` / `comfyui_img2img` / `comfyui_video` 三个工具描述明确「**只能用本分类工作流**」

  - 新增 `@filter.regex` 兜底 handler，容忍 `[图片] 图生图` 这类占位前缀（AstrBot 会把图片转成 `[图片]` 文本，导致 `command` 的 `startswith` 匹配失败 → 消息落到 LLM）
  - **仅飞书生效**（内部判 `platform != 'lark'` 直接返回），QQ 原有命令逻辑完全不变
  - 覆盖：图生图 / 图生视频 / 反推
- 🖼️ **飞书最近图片缓存（支持「先发图 → 再发命令」）**
  - 新增消息监听器缓存用户发来的图片（按会话，10 分钟有效）

- 📦 **飞书图片超限自动压缩**

  - 解决 `234006 The file size exceed the max value`

## 1. 快速开始

### 1.1 前置条件

| 条件 | 说明 |
|------|------|
| ComfyUI | 已部署并运行，默认地址 `127.0.0.1:8188` |

> **什么是 API 格式的工作流？** 在 ComfyUI 中加载工作流 → 右上角「Save (API Format)」导出的 JSON 文件。普通工作流 JSON 不能被插件直接使用。

将整个插件文件夹放入 AstrBot 的 `data/plugins/` 目录，重启 AstrBot 即可自动加载。

启动后日志会输出 WebUI 地址：

```
[ComfyUI] WebUI: http://127.0.0.1:8898 | 工作流目录: E:\xxx\workflows | 上传模式: local
```

### 1.3 首次配置四步走

```
Step 1 ─ 打开 WebUI → http://127.0.0.1:8898
Step 2 ─ 点击右上角 ⚙ 设置 → 配置工作流目录、输出目录、ComfyUI 地址
Step 3 ─ 在工作流管理器中为每个工作流设置「分类」标签
Step 4 ─ 在节点配置面板中标记正面提示词节点、分辨率节点等
```

完成后即可在 QQ 群内发送：

```
/画 一个白发Miku
```

### 1.4 目录结构速览

```
工作流目录/
├── Anima动漫画图.json       ← API 格式工作流

```

## 2. 命令详解

所有命令均在 QQ 群内以 `/` 开头发送。

### 2.1 🎨 `/画` — 文生图

```
/画 一个白发Miku
/画 16:9 一个白发Miku
```

- **第一个参数可选**：图片比例（如 `9:16`、`1:1`、`4:3`、`16:9` 等）
- **剩余部分**：提示词
- 不加比例时使用当前默认比例

### 2.2 🖼️ `/图生图` — 图生图

```
/图生图 把背景改成红色
/图生图 0.7 把背景改成红色
```

**如何提供参考图（二选一）：**

| 方式 | 操作 |
|------|------|
| 引用图片 | 回复/引用一条带图片的消息，然后发送命令 |
| @用户头像 | `@用户` + 发送命令（无引用图片时生效） |

**降噪值**（可选第一个参数）：`0.1` ~ `0.8`，越低变化越小，默认由工作流决定。

**图片编辑**：v3.7.1 起原 `/编辑` 命令已并入 `/图生图`，用法相同（支持 1~10 张参考图）：

```
/图生图 把这个猫换成狗
```

### 2.3 🎬 `/图生视频` — 图生视频

```
/图生视频
```

- 需引用图片或 @用户获取头像
- 当前工作流名称需含 `视频`、`wan`、`ltx`、`animate`、`video` 等关键词（插件据此判断超时时间）
- 视频生成时间较长，超时时间 900 秒

### 2.4 📂 `/工作流` — 工作流管理

```
/工作流            → 显示所有工作流（按分类分组），✅ 标记当前
/工作流 3          → 切换到编号 3 的工作流
/工作流 anime      → 按关键词搜索并切换
/切换 anime        → 同上，快捷方式
```

选择后 **10 秒内**回复数字可切换。

### 2.5 📐 `/比例` — 图片比例

```
/比例              → 显示所有可用比例
/比例 3            → 切换到编号 3
/比例 16:9         → 按名称切换
```

可用比例列表：`1:1` `3:4` `4:3` `9:16` `16:9` `2:3` `3:2`

### 2.6 🎚️ `/分辨率` — 质量等级

```
/分辨率            → 显示所有质量等级
/分辨率 2          → 切换到编号 2
/分辨率 1080p      → 按名称切换
```

| 等级 | 像素数 | 说明 |
|------|--------|------|
| 480p | ~39.9 万 | 快速出图，SD 质量 |
| 720p | ~92.2 万 | 标清（默认） |
| 1080p | ~207 万 | 高清 |
| 2K | ~369 万 | 超清 |
| 4K | ~829 万 | 原画，最慢 |

> **质量与比例的关系**：质量等级决定图片的总像素数，比例决定宽高比。插件自动计算实际的 `width` 和 `height`。例如 720p + 9:16 = 720×1280。

### 2.7 🚀 `/执行` — 执行工作流

```
/执行 提示词
```

- 执行当前工作流，**不限制分类**
- 适用于未设置分类的工作流或需要临时覆盖分类的场景

### 2.8 📊 `/队列` — 查看队列

```
/队列
```

显示 ComfyUI 当前队列状态：运行中任务数 + 等待中任务数。

### 2.9 ⏹️ `/停止` — 停止生成

```
/停止
```

停止**当前用户**提交的正在生成的任务，不影响其他用户。

### 2.10 🎲 `/随机图` — 随机图片

```
/随机图          → 随机生成 1 张
/随机图 5        → 随机生成 5 张（最多 10 张）
```

- 从魔导书随机池中抽取标签，合并固定标签后生成随机图片
- 需先在魔导书 WebUI 中将数据源加入「随机池」

### 2.11 ↩️ `/撤回` — 撤回消息

```
/撤回
```

撤回本插件在该会话中最近发送的一张图片/视频。

> ⚠️ 撤回依赖 OneBot API 返回的 `message_id`，仅 QQ 平台支持。Telegram/Discord 等平台不可用。

### 2.12 🔍 `/提示词` — 查询提示词

```
@bot 提示词     ← 需引用一张 bot 发过的图片
```

返回该图片生成时使用的提示词。支持扩写后文本节点配置的工作流，会返回扩写后的完整提示词（而非用户原始输入）。

> 提示词记录保存在 `data/prompt_log.json`，默认保留 3 天，可在管理面板或 AStrBot 配置中调整 `prompt_log_days`。

### 2.13 ❓ `/帮助` — 帮助

```
/帮助
```

显示当前工作流名称和所有可用命令。

### 2.14 🔢 数字回复 — 选择确认

发送 `/工作流`、`/比例`、`/分辨率` 等命令后，插件会列出选项列表，在 **10 秒内**直接回复数字即可选择。例如：

```
你: /工作流
机器人: 请选择工作流：
  1. Anima动漫画图 ✅
  2. FLUX漫转真
  3. 基础图生视频
你: 2          ← 10 秒内回复数字
机器人: 已切换到 FLUX漫转真
```

### 3.3 功能详解

#### 工作流管理器（左侧栏）

| 角色 | 按钮 | 说明 |
|------|------|------|
| 🎯 正面提示词 | `setPromptNode` | 插件往此节点写入用户输入的提示词 |
| 🚫 负面提示词 | `setNegativeNode` | 插件往此节点写入通用负面词 |
| 📐 分辨率 | `setResNode` | 插件覆盖此节点的宽高 |

| 📤 图片上传 3 | `setLoadImageNode2` | 传入第三张参考图 |
| 📝 扩写后文本 | `setExpandedTextNode` | 从此节点读取扩写后的提示词，替代原始输入存入提示词记录 |

- **随机池（🎲）**：将子分类加入随机池，`/随机图` 命令会从中各随机抽取一条
- **数据管理**：支持新增/编辑/删除条目，批量导入/导出，管理数据源和分类目录

## 4. 工作流配置

### 4.1 工作流文件要求

插件只能读取 **API 格式** 的工作流 JSON。如何导出：

```
ComfyUI → Load 工作流 → 右上角 "Save (API Format)" → 得到 .json 文件
```

### 4.2 工作流分类

每个工作流可以设置一个分类标签，分类决定了该工作流可以被哪些命令使用：

| 分类 | 可用命令 |
|------|---------|
| `画` | `/画`、`/执行` |
| `图生图` | `/图生图`、`/执行` |
| `图生视频` | `/图生视频`、`/执行` |
| `编辑` | `/图生图`、`/执行`（`/编辑` 已于 v3.7.1 并入 `/图生图`） |
| （无分类） | `/执行` 仅 |

在 WebUI 的工作流管理器中右键/菜单设置分类。

### 4.3 命令与工作流的关联

插件内置的分类校验逻辑：

- `/画` → 当前工作流分类必须为「画」
- `/图生图` → 当前工作流分类必须为「图生图」
- `/图生视频` → 当前工作流分类必须为「图生视频」
- `/编辑` → 当前工作流分类必须为「编辑」
- `/执行` → 使用当前工作流，不限分类

插件会记住每个群/私聊最近使用过的工作流（上下文记忆）。
**但命令不会自动搜索并切换到匹配分类的工作流**——如果当前工作流分类不匹配，会直接拒绝并提示。
请先通过 `/工作流` 命令或 WebUI 手动切换到正确的工作流。

### 4.4 节点配置详解

为了让插件正确操控工作流，需要标记关键节点。打开 ComfyUI，找到工作流中的以下节点，记下其 **节点 ID**（鼠标悬停在节点上显示的数字），然后在 WebUI 节点配置面板中设置：

#### 正面提示词节点

通常是 **CLIP Text Encode (Prompt)** 节点的 `positive` 输入。插件会将用户输入的提示词写入此节点的 `text` 字段。

#### 负面提示词节点

通常是 **CLIP Text Encode (Prompt)** 节点的 `negative` 输入。插件会写入通用负面词。

#### 分辨率节点

通常是 **Empty Latent Image** 节点。插件会覆盖其 `width` 和 `height`。

#### 图片上传节点

通常是 **Load Image** 节点。插件会在图生图/编辑时传入参考图路径。

> **不是所有节点都需要标记！** 只标记你要让插件控制的节点。例如你的工作流已经写死了分辨率，就不标记分辨率节点。

### 4.5 禁用节点组

WebUI 中可以为工作流配置「节点组」（Group）。在设置面板的「禁用组」中勾选后，对应组内的所有节点将**从工作流中移除**。适用于：

- 条件性启用/禁用 ControlNet
- 开关 LoRA 加载
- 不同质量模式之间的切换

## 5. 魔导书系统

### 5.1 什么是魔导书？

魔导书是插件内置的提示词标签搜索引擎，包含超过 **24000 条角色数据**和大量画师/服装/场景/光影/姿势/镜头标签。帮助用户快速找到合适的提示词标签。

### 5.2 数据来源

```
data/
├── anima/
│   ├── characters.json     24000+ 角色（按 IP、发色、瞳色、人数分类）
│   ├── artists.json        画师（按热度排序）
│   └── clothing.json       服装（按分类、颜色）
├── scene/environment.json  场景/环境
├── lighting/lighting.json  光影/色调
├── shot/framing.json       镜头/构图
├── pose_action/            动作/姿势/表情
└── custom/                 用户自定义扩展（可自行添加）
```

### 5.3 在 WebUI 中使用

1. 点击正面提示词框上方的 📖 **魔导书** 按钮
2. 底部弹出面板，选择数据维度（角色/画师/服装/场景等）
3. 输入关键词搜索，或使用筛选维度缩小范围
4. 点击标签 → 自动复制到剪贴板

### 5.4 固定标签（Pin）系统

在魔导书中可固定（📌）某个条目，固定后的标签会自动合并到每次生图的 prompt 中：

- 同一子分类只能固定一条
- 固定标签有冲突检测：如果用户 prompt 中已包含相同标签，不会重复追加
- 性别/人数冲突检测：用户写 `1girl` 时，固定标签中的 `1girl` 不追加
- 外貌冲突检测：用户写了头发/眼睛颜色时，固定标签的同类描述不追加
- 固定标签在 `/随机图` 命令中始终被包含

### 5.5 随机池（Random Pool）

将子分类加入随机池后，每次 `/随机图` 会从每个子分类中随机取一条标签：

- 每个子分类可单独加入/移出随机池（🎲 按钮）
- 已固定的子分类不参与随机抽取
- 抽取的标签全局去重，避免相同标签重复出现
- 随机池状态在顶部固定栏显示

### 5.6 LLM 魔导书管理（v3.1.6+）

魔导书启用的前提下，LLM 可以通过聊天直接操作魔导书：

| LLM 工具 | 功能 |
|----------|------|
| `comfyui_search_tags` | 搜索标签（不传 source 搜全部，传 source 搜单个数据源） |
| `comfyui_list_grimoire` | 列出当前随机池和固定标签 |
| `comfyui_manage_pool` | 添加/移除数据源到随机池（action: add/remove） |
| `comfyui_manage_pin` | 固定/取消固定标签（action: pin/unpin） |

> 魔导书开关关闭后，LLM 只能搜索 Anima 旧库，所有修改工具都会拒绝操作。

### 5.7 自定义扩展数据

在 `data/custom/` 目录下创建 `.json` 文件，格式如下：

```json
[
  {
    "name": "显示名称",
    "tags": "逗号分隔的提示词标签",
    "category": "分类名（可选）",
    "note": "备注（可选）"
  }
]
```

重启插件即可生效。

| `comfyui_manage_pin` | 管理固定标签 | `action`（pin/unpin）, `source`, `name`, `tags` |

### 6.2 图片处理机制（重要）

当用户通过消息发送图片时（如引用图片、上传图片），插件会自动拦截 LLM 请求：

```
用户发送图片
    ↓
@filter.on_llm_request() 拦截
    ↓
图片下载到本地临时目录（base64 → PNG / HTTP → 下载）
    ↓
以文本形式注入 prompt：
  "[用户发送了图片，已保存到: /path/to/image.png]"
    ↓
LLM 使用此路径调用 img2img / video / edit 等工具
    ↓
图片上传到 ComfyUI 后，临时文件即时删除
    ↓
定时清理兜底：每 1 小时清理超过 24 小时的残留文件
```

**适用场景**：纯文本模型（如 DeepSeek V4 Flash）不支持 `image_url` 消息类型时，此机制确保 LLM 仍能感知用户发图并调用对应工具。

### 6.3 工具调用示例

用户在 QQ 中说："帮我把这张照片转成动漫风格"

```
LLM 内部流程：
1. 感知到用户引用了图片
2. 插件将图片保存为本地路径
3. LLM 调用 comfyui_img2img(prompt="转成动漫风格", image_url="...路径...")
4. 插件提交 ComfyUI → 下载结果 → 发送到群
```

## 8. 常见问题

### Q1: WebUI 卡顿/掉帧

这是 `backdrop-filter: blur()` 玻璃态效果的已知问题。

**解决方案**：
- ✅ 推荐使用 **Firefox** 浏览器（全速运行）
- ⚠️ Edge/Chrome 可能因 GPU 黑名单降级为 CPU 渲染导致卡顿

### Q2: 生成失败/超时

排查步骤：

1. 确认 ComfyUI 正在运行 → 浏览器打开 `http://127.0.0.1:8188`
2. 确认 ComfyUI 地址配置正确 → WebUI 设置面板检查
3. 确认 ComfyUI 已加载所需模型（Checkpoint、LoRA、ControlNet 等）
4. 检查 AstrBot 日志中的具体报错信息

### Q3: 工作流提交报错 "节点未找到"

- 确认工作流文件是 **API 格式** 导出的（非普通 Save 格式）
- 确认节点 ID 配置正确（WebUI 节点配置中标记的 ID 与工作流 JSON 一致）
- 如果工作流更新了，需要重新标记节点

### Q4: 撤回功能不可用

撤回依赖 OneBot API 返回的 `message_id`：
- **QQ 平台 (OneBot)**：完整支持
- **Telegram / Discord / 飞书**：不支持撤回，其余功能正常

### Q5: 多个用户同时使用

- 插件支持多用户并发
- 每个用户的任务独立排队（`_generating_locks[user_id]`）
- `/停止` 仅停止当前用户自己的任务

### Q6: 图片上传失败

- **本地模式**：检查 ComfyUI input 目录是否存在且有写入权限
- **远程模式**：检查 ComfyUI 的 `/upload` 端点是否可访问

### Q7: 画廊不显示图片

- 检查「输出目录」配置是否正确
- 只有插件生成的图片才会显示在画廊中
- 画廊最多扫描 5000 张图片（防止 OOM）

### Q8: 浏览器缓存导致 WebUI 不更新

修改 `webui.html` 后，按 `Ctrl+F5` 硬刷新清除缓存。部分浏览器需要多次刷新。
